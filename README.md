# Filter Search Mockaroo

A responsive React + TypeScript + Tailwind CSS application that provides real-time filtering and search across a mock dataset.

## Features

- Real-time search by name, email, or gender
- Clean and responsive UI built with Tailwind CSS
- Mock data generated from Mockaroo

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation & Development

1. Clone the repository:
   ```bash
   git clone git@github.com:eng-hijji/filterSearchMockaroo.git
   cd filterSearchMockaroo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Deployment

The project is configured for static hosting (such as GitHub Pages) using Vite with relative base paths (`base: './'`).
